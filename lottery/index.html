How it works & algorithm source

This single HTML contains the page, draw algorithm and synthetic example. It derives the seed, replays the ticket shuffle, rebuilds the prize order and compares actual awards and winning users. It also checks that the configured drand round and public randomness match the official public response.

Internet access is required for the official drand public API. This page trusts that HTTPS source; it does not perform a separate BLS signature check. Missing evidence or an unavailable public response is not a pass. The example uses synthetic prize tiers/participants and a real public round.
